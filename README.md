# Classificacao_de_Profissoes_BERT
Projeto em Python utilizando BERT para classificar textos e obter informações a respeito da profissão do Autor do texto entre: academic, government, private

Para reproduzir o resultado final, apenas rode o run_analysis.py que já tem a configuração final salva (apenas se atente ao batch size do train.py caso a memória disponível no seu computador seja menor).Caso queira testar as outras implementações ou treinar o modelo novamente, é necessário rodar o run_training.py e alterar o model_type ou model_name para alguma das opções comentadas (se desejar ver o deberta por exemplo).
